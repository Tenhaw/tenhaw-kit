# Changelog

## 1.1.0

The CLI adds guided project MCP setup for Codex, Claude Code, Cursor, VS Code Copilot and Gemini CLI. Configuration is previewable, repeatable and preserves existing settings. Optional integration checks report missing local credential names, while MCP verification checks the pinned server identity, tool inventory and a synthetic readiness result. Scaffold results include structured install and build actions.

Six focused hosted application profiles add scoped tools and interactive results for AI business cases, readiness, use-case prioritisation, delivery health, operating models and procurement. The procurement engine produces vendor-neutral questions, evidence criteria, blank supplier scorecards and editable Word exports. The separate developer plugin combines remote calculations with desktop coding skills. Hosted MCP reports omit promotional generator links and footers. Seven submission packages and review plans are prepared source work; directory submission, approval and publication remain separate operations.

## 1.0.1

Generated starters include a strict pnpm build policy that approves esbuild, so the documented pnpm 11 install completes without an interactive build-approval step. The packed scaffold regression now installs and builds the distributed delivery dashboard in an isolated pnpm store. Package, CLI, Python, MCP and plugin release identifiers advance together; calculation contracts, framework content and golden vectors are unchanged.

## 1.0.0 release candidate

Agent-first libraries, CLI, MCP, Python parity, provider skills and five browser-local starters for internal product, portfolio, delivery and transformation tools. Publication status is recorded in the runbook.
