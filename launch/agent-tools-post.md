# Draft: give your coding agent delivery and transformation building blocks

When you build an internal portfolio tracker, the same questions recur: who owns this outcome, what evidence supports this readiness score, and which savings actually change a cost line?

Tenhaw Kit provides small packages and MCP tools for that work. Compose the operating-model and use-case-register libraries in your own app, calculate AI ROI with an explicit cash-realisation assumption, or measure delivery from linked production events. Schemas and shared TypeScript/Python examples make the calculations inspectable.

```sh
npx tenhaw@1.0.0 init product-operating-model internal-portfolio --yes --json
```

The starter uses synthetic examples and browser-local imports. Add your organisation's authentication and persistence before introducing shared customer data. The CLI and local MCP do not send usage pings.
